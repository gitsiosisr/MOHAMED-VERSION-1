# MOHAMED-VERSION-1

## Présentation

Projet réalisé dans le cadre du TP Git CDA.

La page principale se trouve dans le fichier [`index.html`](index.html).

## Ouvrir le projet en local

### Méthode simple

Ouvre le fichier `index.html` avec un double-clic. La page s'affichera directement dans ton navigateur.

### Avec un serveur local

Depuis le dossier du projet, lance la commande suivante :

```bash
python3 -m http.server 8000
```

Puis ouvre cette adresse dans ton navigateur :

<http://localhost:8000>

Pour arrêter le serveur, utilise `Ctrl + C` dans le terminal.
